## 1. Executive Summary

Step 3 implements the biophysical dynamics engine and structural topology feature extractors that empower **Z-DynGNN** (*Z-score Calibrated Dynamics-Aware Graph Neural Network*).

Standard protein Graph Neural Networks treat contact edges as static and symmetric ($A_{ij} = A_{ji}$). In contrast, metallo-$\beta$-lactamases like NDM-1 function through **directional allosteric communication**: mutations at distal positions (e.g., M154L) alter catalytic pocket mobility, but catalytic pocket substitutions do not reciprocally dictate distal dynamics. 

Step 3 computes Elastic Network Models (GNM and ANM), executes Perturbation Response Scanning (PRS), constructs the directional Asymmetric Dynamic Coupling Index ($\text{DCI}_{\text{asym}}$), and stratifies residues into discrete structural bins $\mathcal{S}(i)$ for downstream topology-conditioned conformal risk control.

## 2. Mathematical Formulations & Physical Invariants

### 2.1 Gaussian Network Model (GNM) & Fluctuation Covariance
For $N = 228$ resolved $C_\alpha$ atoms in 3SPU Chain A at distance cutoff $r_c = 8.0$ Å:
$$\mathbf{\Gamma}_{ij} = \begin{cases} -1 & \text{if } i \neq j \text{ and } D_{ij} \le 8.0\,\text{Å} \\ 0 & \text{if } i \neq j \text{ and } D_{ij} > 8.0\,\text{Å} \\ d_i & \text{if } i = j \end{cases}$$

The fluctuation covariance matrix is the Moore–Penrose pseudo-inverse omitting the translational zero mode:
$$\mathbf{C} = \mathbf{\Gamma}^\dagger = \sum_{k=2}^N \frac{1}{\lambda_k} \mathbf{v}_k \mathbf{v}_k^T$$

**Observed Empirical Values:**
* Multiplicity of $\lambda = 0$: Exactly 1 ($\lambda_1 = 0.000000$).
* Fiedler algebraic connectivity: $\lambda_2 = 0.2832$.
* Maximum eigenvalue: $\lambda_{228} = 19.793$.
* Theoretical Mean-Square Fluctuation: $\text{MSF}_i = (\mathbf{\Gamma}^\dagger)_{ii}$.
* Pearson correlation against experimental PDB B-factors: **$r = 0.7077$**.

### 2.2 Anisotropic Network Model (ANM) & 3D Hessian
The 3D Cartesian Hessian matrix $\mathbf{H} \in \mathbb{R}^{3N \times 3N} = \mathbb{R}^{684 \times 684}$ is composed of $3 \times 3$ sub-blocks:
$$\mathbf{H}_{ij} = -\frac{\gamma}{D_{ij}^2} (\mathbf{r}_i - \mathbf{r}_j) (\mathbf{r}_i - \mathbf{r}_j)^T \quad (i \neq j), \qquad \mathbf{H}_{ii} = -\sum_{j \neq i} \mathbf{H}_{ij}$$

**Observed Empirical Values:**
* Eigenvalues $\lambda_1, \dots, \lambda_6 = 0.00000$ (3 translations + 3 rotations).
* First non-zero vibrational mode: $\lambda_7 = 0.00653$.
* Pseudo-inverse $\mathbf{H}^\dagger$ computed over vibrational modes $7 \le k \le 684$.

### 2.3 Perturbation Response Scanning (PRS) & $\text{DCI}_{\text{asym}}$
Under linear response theory, applying unit isotropic perturbation forces at residue $j$ induces displacement response amplitude $S_{ij}$ at residue $i$:
$$S_{ij} = \sqrt{\frac{1}{3} \text{Tr}\left(\mathbf{H}^\dagger_{ij} (\mathbf{H}^\dagger_{ij})^T\right)}$$

The row-normalized Dynamic Coupling Index ($\text{DCI}$) measures response relative to the whole-protein average:
$$\text{DCI}_{ij} = \frac{S_{ij}}{\frac{1}{N} \sum_{k=1}^N S_{ik}}$$

The directional asymmetric dynamic coupling matrix is:
$$\text{DCI}_{\text{asym}}(i, j) = \text{DCI}_{ij} - \text{DCI}_{ji}$$

**Properties & Invariants:**
1. **Strict Antisymmetry:** $\text{DCI}_{\text{asym}}(i, j) = -\text{DCI}_{\text{asym}}(j, i)$ (verified to machine epsilon).
2. **Zero Self-Coupling:** $\text{DCI}_{\text{asym}}(i, i) = 0.0$.
3. **Driver / Sensor Duality:**
   $$\text{Driver}(j) = \frac{1}{N-1} \sum_{i \neq j} \text{DCI}_{\text{asym}}(i, j), \qquad \text{Sensor}(i) = -\text{Driver}(i)$$
   * $\text{Driver}(j) > 0$: Residue $j$ acts as an allosteric driving source.
   * $\text{Sensor}(i) > 0$: Residue $i$ acts as a dynamic sensor receptive to distal mutations.

**Biological Validation on Known Functional Sites:**
* **Catalytic Zinc Coordinating Residues:**
  * $\text{His120}$: $\text{Sensor} = +0.4007$
  * $\text{His122}$: $\text{Sensor} = +0.1723$
  * $\text{Asp124}$: $\text{Sensor} = +0.2747$
  * $\text{His189}$: $\text{Sensor} = +0.3526$
  * $\text{Cys208}$: $\text{Sensor} = +0.5185$
  * $\text{His250}$: $\text{Sensor} = +0.4021$
* **Interpretation:** All six zinc-binding residues act as strong dynamic sensors, confirming that active site mobility is tuned to absorb conformational changes from the protein scaffold.
