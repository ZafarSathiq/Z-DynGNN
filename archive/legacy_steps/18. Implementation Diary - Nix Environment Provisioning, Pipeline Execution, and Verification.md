### Entry 04: Debugging & Repairing Nix Manifests (`flake.nix` & `shell.nix`)
* **Problem:** Running `nix flake show` produced a syntax error:
  ```
  error: syntax error, unexpected '='
  at /home/dev/code/Z-DynGNN/flake.nix:27:21:
      27|           shellHook = ''
  ```
* **Root Cause Analysis:**
  * In `flake.nix`, the `buildInputs = with pkgs; [` block was missing its closing bracket `];` before `shellHook`, and `shellHook` was missing its closing delimiter `'';`.
  * In `shell.nix`, line 12 was also missing `];`.
* **Edits Applied:**
  * Patched `flake.nix`:
    ```nix
              buildInputs = with pkgs; [
                python311
                uv
                git
                curl
                cacert
                zlib
              ];

              shellHook = ''
                export LD_LIBRARY_PATH="${pkgs.stdenv.cc.cc.lib}/lib:${pkgs.zlib}/lib:$LD_LIBRARY_PATH"
              '';
    ```
  * Patched `shell.nix` similarly.
* **Verification:** `nix flake show` evaluated successfully across all supported architectures (`x86_64-linux`, `aarch64-linux`, `x86_64-darwin`, `aarch64-darwin`).

### Entry 05: Hermetic Virtual Environment Setup via Nix Flake
* **Action:** Executed inside the hermetic Nix development shell:
  ```bash
  nix develop --command bash -c "
    uv venv --python python3.11 .venv && \
    source .venv/bin/activate && \
    uv pip install torch --index-url https://download.pytorch.org/whl/cpu && \
    uv pip install -e '.[dev]'
  "
  ```
* **Rationale for `--index-url https://download.pytorch.org/whl/cpu`:**
  * Default PyPI `torch` wheels download >2.8 GB of NVIDIA CUDA 12/13 runtime libraries (`nvidia-cudnn`, `nvidia-cublas`, `nvidia-cusparse`, etc.), which cause network timeouts and are unnecessary for CPU-based inference and evaluation in WSL2.
  * Installing the official PyTorch CPU wheel resolved in under 18 seconds (187 MiB), providing full geometric deep learning capabilities.
* **Installed Packages:**
  * `torch==2.14.1+cpu`
  * `scipy==1.17.1`, `numpy==2.4.6`, `pandas==3.0.6`, `biopython==1.88`, `scikit-learn==1.9.1`, `matplotlib==3.11.2`, `openpyxl==3.1.5`
